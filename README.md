# dtvi-project — IDS (Intrusion Detection System) со вештачка интелигенција

Ова е конечната, консолидирана верзија на проектот. Сѐ што е потребно е тука, копирано од
`NSL-KDD-IDS/`, `dtvi_project/` и Downloads (менторовите забелешки).

## Структура

- **paper/** — академскиот документ
  - `IDS-system-Sara-Karachanakova.docx` / `.pdf` — конечната, поправена верзија (38 страници, вклучувајќи ја валидацијата врз UNSW-NB15 во делот 9)
  - `КРАТОК ГОВОР ЗА ОДБРАНА НА ПРОЕКТ.docx` — говор за одбрана, ажуриран со точните бројки
  - `figures/` — графици за NSL-KDD (делови 3–6), регенерирани од зачуваните модели, со Македонски ознаки
  - `figures_unsw/` — графици за UNSW-NB15 (делот 9)
  - `source_notes/` — оригиналните извори што беа искористени за поправките:
    - `IDS-system-so-zabeleski-od-mentor.docx` — верзијата со track-changes забелешки од проф. Ристевски (веќе преработени во конечниот документ)
    - `IDS_feedback_document.docx`, `Improved_IDS_Document.docx` — постара анализа/фидбек

- **code/** — целосниот изворен код и зачувани модели за NSL-KDD (без `venv/` — регенерирај со `pip install -r requirements_local.txt`)
  - `IDS_train.ipynb` — Colab notebook за тренирање
  - `predict_local.py` — локално предвидување врз нови податоци
  - `app_gradio.py` — демонстрациона веб-апликација
  - `models/binary/`, `models/multiclass/` — зачувани модели + извештаи + summary.csv
  - `KDDTest+.txt` — тест-множество

- **code_unsw/** — валидација на истата методологија врз UNSW-NB15 (делот 9 од трудот)
  - `train_unsw.py` — тренирање на истите 4 модели (binary + multiclass), локално (не во Colab)
  - `gen_figures_unsw.py` — генерирање на графиците во `paper/figures_unsw/`
  - `data/` — официјалниот training-set/testing-set (Kaggle, "dhoogla/unswnb15", parquet формат)
  - `models/binary/`, `models/multiclass/` — зачувани модели (Random Forest е компресиран со
    `joblib.dump(..., compress=3)` — proto има 133 категории, некомпресирано растеше до >800MB)

- **app_demo.py** (во коренот) — комбинирано Gradio демо, ги користи и NSL-KDD и UNSW-NB15
  моделите во ист интерфејс (избор на множество податоци/режим/модел). Три начини да се тестира
  пример: анализа на цел датасет, случајна конекција од тест-сетот, или **рачно внесени сопствени
  вредности** во уредлива табела, преполнета со типична нормална конекција (медијана/најчести
  вредности од нормалниот сообраќај) што слободно се менуваат пред предвидување.
  ```bash
  pip install -r requirements_demo.txt
  python3 app_demo.py     # http://127.0.0.1:7860
  ```
  (Постариот `code/app_gradio.py`, само за NSL-KDD, е задржан непроменет.)
